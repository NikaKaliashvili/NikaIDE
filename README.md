# Custom C++ Text Editor

A simple text editor built from scratch in **C++** using the **Win32 API**.

I started this project because I wanted to understand how text editors and IDE features actually work under the hood.

## Project Status

This project is **actively being developed** and is still far from finished.

The current goal is not to compete with existing editors, but to learn how the underlying systems work and gradually build more advanced features.

## ✨Current Features

* Custom text editing system
* Multiple lines of text
* Cursor movement
* Keyboard input
* Arrow-key navigation
* Backspace and Enter handling
* Scrolling
* Custom font rendering
* Basic syntax highlighting
* Language selection
* File handling
* Basic C++ compilation support

## 🔨 Currently Working On

* Improving the custom editor
* Building a lexer for syntax highlighting
* Better cursor and text management
* Autocomplete
* Custom IntelliSense-like functionality
* Improving the overall UI
* Supporting more programming languages

## Technologies

* **C++**
* **Win32 API**
* **Windows GDI**
* Custom lexer *(in development)*
